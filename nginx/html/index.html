안부링

누적 조회수 불러오는 중

프로젝트 소개

안부링은 혼자 사는 어르신의 일상 안부를 보호자가 편히 확인할 수 있도록 돕는 서비스 입니다

주요 기능

질문 설정 / 전화 수신 / 안부 확인 / 캘린더 자동 등록

사용 기술

안드로이드 앱은 어르신용, 보호자용 화면 제공. 반응형 웹 대시보드는 모든 기기에서 일상을 확인할 수 있게 함. 서버는 Node.js와 AWS로 음성 저장, 변환을 처리. AI가 답변을 항목별로 요약. 서버 인프라는 AWS SAM으로 코드로 관리

팀 소개

황초희 : 백 / 서유현 : 프론트 / 손석환 : 보조

API 연결 확인

페이지를 열거나 새로고침하면 조회수가 증가합니다.
